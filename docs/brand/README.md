# procly brand

| File | Use |
|---|---|
| `mark.svg` | The logo. A ring that keeps going, with a green dot where it restarts. |
| `mark-bare.svg` | The ring without its tile. Takes `currentColor`, for places that already have a background. |
| `mark-512.png` | Raster mark for places that don't take SVG. |
| `social-preview.png` | 1280×640 card for the GitHub repo and link previews. |

The wordmark is "procly", always lowercase, set in Inter SemiBold with -0.035em tracking.

## Colors

One brand color. Green means running; it is not decoration.

| Name | Hex | Use |
|---|---|---|
| Ink | `#0F1115` | Text, the mark's tile, dark backgrounds |
| Graphite | `#1D2026` | Dark surfaces |
| Steel | `#6B6F76` | Muted text on light (4.7:1 on Paper) |
| Fog | `#9A9EA5` | Muted text on dark (7.0:1 on Ink) |
| Mist | `#E4E4E1` | Borders on light |
| Paper | `#F7F7F6` | Light background |
| Signal 300 | `#6FD08C` | Green text on dark |
| Signal 500 | `#2EAA5C` | The mark's dot. Too light for small things on Paper (2.8:1) |
| Signal 600 | `#24994F` | Green icons and bars on light |
| Signal 700 | `#1A7F37` | Green text on light |

Status colors, only for state: amber `#9A6700` / `#E3B341` (restarting, light / dark), red `#C4262E` / `#FF7B72` (errored, light / dark).

## Type

Inter for the wordmark and UI, JetBrains Mono (or the system monospace) for data, commands and logs. No gradients, no glow, no second accent color.
